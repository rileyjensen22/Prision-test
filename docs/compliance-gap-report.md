## How to use this

1. Hand the table to counsel and the customer. Each row needs an owner's name and a date.
2. Replace placeholder values in `config/compliance.yaml` (retention, minimum out-of-cell, appeal window, rate caps) only after the matching row is answered, and record the decision in `docs/DECISIONS.md`.
3. Keep this file in step with `ASSUMPTIONS.md`: a new assumption is a new row.
