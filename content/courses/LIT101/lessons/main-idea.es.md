# Cómo encontrar la idea principal

Cada párrafo se construye alrededor de una idea principal. Las demás oraciones dan detalles que la apoyan. Para encontrarla, pregúntese: ¿de qué trata sobre todo este párrafo?

- Lea primero todo el párrafo.
- Fíjese en la primera y la última oración.
- Diga la idea con sus propias palabras.
